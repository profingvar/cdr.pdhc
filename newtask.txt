THE LESSON FROM THE FIRST ATTEMPT, worth keeping
------------------------------------------------
cdr1 has no bind mount, so `/app` is baked and a deploy is a `--build`. The
first attempt's copy step did not run, the build did, and it rebaked the OLD
source — green container, /healthz 200, nothing changed. A rebuild of unchanged
files is indistinguishable from a successful deploy.

So for any baked-image service: compare remote hashes against local and ABORT
without building if they differ. The script that did it is
scratchpad/deploy874.sh; the shape is worth reusing.
